# Riset Kecil Customer Churn

## 1. Formulasi Masalah
Bagaimana memprediksi pelanggan yang berpotensi churn pada layanan telekomunikasi serta mengetahui faktor yang memengaruhi prediksi tersebut?

## 2. Research Gap
Penelitian sebelumnya banyak menggunakan metode machine learning untuk prediksi customer churn. Namun, tidak semua penelitian memberikan interpretasi terhadap hasil prediksi. Oleh karena itu, penelitian ini menggabungkan CatBoost untuk prediksi dan SHAP untuk menjelaskan faktor yang memengaruhi churn.

## 3. Peluang Pengembangan
Mengembangkan model prediksi customer churn yang tidak hanya memiliki performa baik, tetapi juga dapat menjelaskan faktor penyebab pelanggan berpotensi churn.

## 4. Rencana Topik
Prediksi Customer Churn pada Layanan Telekomunikasi Menggunakan CatBoost dengan Interpretasi SHAP untuk Mendukung Strategi Retensi Pelanggan.
